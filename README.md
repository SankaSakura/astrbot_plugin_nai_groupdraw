# QQ 群画图 v1.18.0

在群里 @机器人发送 `/标识`，可查看当前群标识。私聊同一机器人发送 `/标识`，可查看自己的用户标识，用于填写插件配置。

## 群绑定和私聊

在白名单群 @机器人发送 `/绑定群`，然后在同一机器人的 QQ 私聊发送 `/草稿` 或 `/出图`。每次群内绑定或续期从当时起有效 48 小时。私聊 `/当前绑定` 查看群和到期时间，`/解绑群` 解除绑定。要换群，在另一个白名单群重新绑定。如果两个场景的身份不一致，私聊发送 `/绑定码`，由本人在目标群发送带验证码的绑定命令。

私聊和绑定群读取同一份个人草稿、预设开关和群额度。群共享预设只能在群里新建或编辑，私聊可读取及启停个人选择。DS 也遵守这些限制。换绑只影响以后的请求，历史仍归生成时的群。绑定到期后到群里重新绑定即可继续。成员离群后，已有授权最长可继续至剩余 48 小时到期；移出白名单或加入黑名单会立即阻止后续使用。

私聊发送 `/导出我的私聊图库` 可下载本人在当前绑定群下的私聊 PNG。发送 `/清空我的私聊图库` 查看群和张数，按回复在两分钟内确认；图片集合发生变化时需要重新确认。发送 `/清空我的私聊提示词记录` 删除本人该群的私聊提示词与重画记录。私聊结果只回私聊，群内管理员导出 ZIP 只包含群聊原图。群内管理员清空图片或清空全群提示词时，两种来源都计入。公开图卡可在绑定群的私聊中复用，私聊图卡仅作者能在绑定该群的私聊中查看或重画。

在 AstrBot 的插件页用本 ZIP 更新并重载同名插件。在手机 QQ 群实际 @机器人，发送 `/画图` 即可看到自己的草稿。完成绑定后也可在私聊操作。绘图指令自行处理，未配置对话模型也可使用。

## DeepSeek 自然语言指令

指令中的 DS 大小写通用，也可以发 `/ds整理` 和 `/ds出图`。整理完成后，插件只汇报实际发生的改动。

在本插件配置填入 DeepSeek API Key（也可设置环境变量 `DEEPSEEK_API_KEY`），启用「/DS整理 和 /DS出图」并保存。默认关闭；使用独立的 DeepSeek 官方 API 配置，无需设置 AstrBot 默认聊天模型。

- `/DS整理 把角色1改成银发，开启 N2` 更新发起人在本群的草稿和预设选择。可要求新建本群预设。修改已有共享预设时以 `/DS整理 修改本群预设 P3` 开头，再写要改的内容。将 P3 替换为当前群实际编号。官方 N 预设只读。
- `/DS出图 横图，画水彩雪夜车站` 从空白开始生成一张。`/DS出图 沿用草稿的角色1，改成雨夜街头，用 N2` 只为本次采用指定字段和预设；本人保存的草稿和预设开关保持原样。可同时附图或回复图片，并指定参考模式。
- `/ds出图 使用当前草稿，画一个脆皮炸鸡腿` 沿用自己的草稿，无需填写预设编号。想同时套用已开启的预设，可加上“用我已开启的预设”。
- 两条指令必须带斜杠。普通出图、聊天、按钮和引用里的旧指令不会启动本插件的 DS。请求正文、本人本群的草稿字段、群内预设名称及个人开启项用于解析；明确修改某个本群预设时附上该项内容。图片由插件传给 NovelAI。需要澄清时，请重新带上 DS 指令和完整要求。
- 每分钟同一成员在本群最多调用 4 次，每群最多 20 次；出图另计原有群绘图额度。权限、编号归属、计划校验及执行均在插件内完成。模型无管理员工具。

## 随出图指令附参考图

长按本群里想用的图片，选择「回复」，在回复框中 @机器人 并发送 `/出图 参考模式：服装`。可以引用任何成员的图片，发送多久都可以，只要 QQ 提供的图片仍可读取。需要先验证时，回复原图发送 `/测试引用`，机器人会下载并解码图片，全程不请求 NovelAI。

插件会读取 QQ 原始事件中的引用索引，匹配对应的消息和附件。若无法定位原消息或读取图片，可以在同一条消息里附图并发送 `/出图 参考模式：服装`。进度消息会标明「引用图片」或「本条附图」。同时回复图片并附上新图时，优先使用本条附图。QQ 提供了原消息 ID 或引用索引，但引用无法解析时，本次出图会停止。插件只检查当前指令事件，不订阅群全量消息。

点草稿的「出图」会在输入框填入 `/出图 参考模式：角色`。可以把「角色」换成「画风」「服装」或「角色+画风」，在同一条 @机器人 消息中附图并发送。没有附图也没有引用时，照常使用你在本群的草稿和当前预设。直接发 `/出图` 并附图时默认使用角色模式。同一条消息中的多张附件使用同一模式，强度为 1。图片下载或解析失败时，机器人会提示重新附图。

发送后，「正在画」会显示本次提交的参考模式和图片数量。若显示「本条消息未收到参考图」，此次按普通草稿出图。

V5 的服装参考使用 `costume`。v1.12.0 和 v1.12.1 记录的服装图，点击「按原设置重画」时也会自动采用修正后的参数。

普通出图每次只取当前消息的附件。「按原设置重画」会复用随原图记录保存的参考图。群内其他允许绘图的成员也可以通过原图卡片重画。「用我的预设重画」使用原图草稿和点击者的当前预设。

自定义键盘的「出图」按钮支持上述预填。使用 QQ 平台固定键盘模板时，请将已配置模板里的「出图」按钮数据同步改为 `/出图 参考模式：角色`，并关闭自动发送。

## 画风与质量预设

本群共享预设按创建顺序从 P1 编号，各群分别计数。升级后首次加载插件时，所有已有群自动分配新号。从旧版本直接升级时，同一事务会把每位成员已开启的 G 编号改写为所属群的 P 编号，保留启用项及拼接顺序。G 编号和含 G 编号的旧按钮退役，请发送 `/预设` 查看新编号。

在群中 @机器人 发送 `/预设` 或点草稿上的「预设」。列表按页显示官方预设和本群共享预设，每项可以查看详情、启用或停用。首次使用时默认全部关闭。「我的拼接顺序」从左到右就是实际追加的顺序。选择仅对你在当前群生效，重启后保留。

| 编号 | 官方预设 | 作用栏 |
|---|---|---|
| N1 | 正向轻量 | 画面正向 |
| N2 | 正向标准 | 画面正向 |
| N3 | 反向轻量 | 画面负向 |
| N4 | 反向重度 | 画面负向 |
| N5 | 人物向 | 画面负向 |
| N6 | 兽人向 | 画面负向 |

在白名单群中，所有可用绘图的成员都可以新建和修改本群的自定义预设。点「新建预设」会预填模板，也可以一次发送这条多行消息：

```text
/预设 新建 水彩
正向：watercolor, textured paper
反向：hard outlines
```

至少填一侧。保存后查看机器人返回的 P 编号。点「详情 → 编辑预设」可以改昵称和两侧内容。手动编辑如 `/预设 修改 P1` 后另起一行填写 `昵称：晨光水彩` 或 `正向：…`。省略的栏保留原值，发送空栏如 `反向：` 会清空该侧。改名后已启用该项的人会继续使用同一预设。官方六项只读。

发送 `/预设 启用 N2 P1 N5` 按顺序追加这三项，P1 换成本群实际编号。发送 `/预设 停用 P1` 只移除这一项，`/预设 全关` 清空自己的选择。重复启用同一编号只计一次。普通出图与快捷出图都在提交时读取最新版本，只追加到基础画面正负向，角色栏独立。

「查看提示词」分栏展示原始草稿的画面和角色提示词，以及生成时各预设的名称、编号和正反向原文。可在同一张提示词卡片上按自己的状态开启或关闭这些预设；每行最多三个开关，每页最多四项，底行用于覆盖草稿和翻页。预设后来改过时，卡片注明开启将使用当前版本。两种重画都重新抽取种子。「按原设置重画」复用原图的生成参数和当时的预设。「用我的预设重画」读取原图的草稿提示词、角色和画幅，按点击者在本群当前的选择重新拼接预设。两种操作都保留点击者正在编辑的草稿。v1.11.0 开始保存实际提交的生成参数；更早的记录按旧版固定参数和已存的草稿、预设还原。新图单独记录本次实际使用的预设，旧图仍显示原有记录。「覆盖草稿」只替换点击者的画面和角色提示词，保留点击者的画幅与本群预设开关、顺序。

## 本群图库

从安装此版本起，每次收到 NovelAI 返回的 PNG，插件先把全部原图存入本群目录，再向 QQ 回复。原图保留 NovelAI 写入文件的元数据。存放位置是 AstrBot 持久化目录 `data/plugin_data/astrbot_plugin_nai_groupdraw/gallery/<群作用域哈希>/images/`，按机器人实例与群隔离。升级前只保留了提示词的记录无法补回原图。

| 在绘图白名单群 @机器人 | 效果 |
| --- | --- |
| `/图库权限` | 检查自己在本群的权限，显示 QQ 自动识别或手动授权的结果。 |
| `/导出图库` | 把当前群的群聊原图打包成 ZIP 发到本群。原图继续保留。 |
| `/清空图库` | 永久删除本群已归档的原图。个人草稿、重画记录、额度和其他群的图库均保留。已发送的 QQ 文件仍需在 QQ 中管理。 |
| `/清空全群提示词记录` | 清除本群所有成员的历史提示词和重画记录。旧图的「查看提示词」「覆盖草稿」「再来一张」随之失效，原图和当前草稿保留。 |

这三条管理指令在 `/help` 中列出，直接发文字即可。公开图卡的记录保存在 SQLite 中，由本群管理员统一清理。成员可以自行清理个人私聊记录。图库 ZIP 只包含原始 PNG，包括图片自带的 NovelAI 元数据。

**总管理员**可在所有白名单群执行这三条指令，即使在 QQ 群内是普通成员。请本人私聊机器人发送 `/标识`，复制「你的用户标识」，填入插件配置顶层的「总管理员」并保存。支持多位，每行一人。发送 `/图库权限` 即可验证。删除对应标识并保存即可撤销这项跨群授权。

**本群管理员**按 QQ 群角色识别。群主和管理员自动获得权限，消息缺少角色时插件会向 QQ 查询。若 QQ 无法返回角色，可在「群白名单 → 对应群 → 图库管理员」中每行填写一人的用户标识并保存。这项授权仅在该群生效，且仅在 QQ 未返回明确角色时使用。

导出走 QQ 群文件上传与被动回复接口，需要当前机器人具备相应权限。文件超过平台限制或 QQ 拒绝发送时会报告失败。

图库持续占用磁盘，直到管理员清空。打包期间需要约相当于本群原图总大小的额外空间，临时 ZIP 在发送完成或失败后释放。每个插件实例同时处理一个导出。新图和清空以本群图库的写入顺序为准，导出快照建立后归档的图片留待下次导出。剩余磁盘空间低于 144 MiB 时暂停新生图。

## 编辑个人草稿

点击角色行最右侧的「删除」，即可移除自己在本群草稿中该角色的正向和负向提示词。草稿随即刷新，其他角色保留原编号。也可直接发送 `/删除角色 2` 删除角色 2。

草稿预览只列已填写的字段，每栏最多显示 36 个字符（含省略号）。编辑按钮会带出原文，图片的「查看提示词」也会显示全文。

草稿标题优先显示发送者的昵称；消息缺少昵称时，QQ 按钮面板用群成员 @ 标签显示名字，纯文本回复显示「你的草稿」。

每个角色占一行，正向和负向按钮并排显示。超过三个角色时，用「下一页」和「上一页」切换角色按钮。点击「添加角色」仍会预填第一个空闲角色编号的正向指令。

| 目的 | 群内指令示例 |
|---|---|
| 查看草稿 | `/画图` 或 `/草稿` |
| 查看绘图说明 | 在群内 @机器人 发 `/help` 或 `/画图 帮助`，尚未加入白名单的群也可以使用 |
| 群内查看群标识，私聊查看本人标识 | `/标识` |
| 切换画幅 | `/横图` 或 `/竖图` |
| 编辑画面 | `/画图 画面正向 train station`，`/画图 画面负向 watermark` |
| 编辑角色 | `/画图 角色1正向 girl, blue hair`，`/画图 角色2负向 hat` |
| 清空一栏 | 只发送字段名，例如 `/画图 画面正向` 或 `/画图 角色1负向`。发送后直接显示更新的草稿和按钮 |
| 用当前草稿生成 | `/出图` |
| 重画某张图 | 点「按原设置重画」或「用我的预设重画」，对应文字指令为 `/原设置重画 图片编号` 和 `/我的预设重画 图片编号` |
| 重画最近成功的一张 | `/再出一张` |
| 清空当前草稿 | 点「清空」或发送 `/清空草稿`，返回默认竖图的空草稿。历史图片仍可重画和查看提示词。旧指令 `/取消画图` 同样只清空当前草稿 |

每个已有角色的正向、负向入口同时保留。角色编号 1～6。按钮可以预填指令，填完发送。只填画面负向、只填角色或不填任何提示词时，也可以点「出图」，空正向会作为空字符串提交。选方向、开草稿或按编辑按钮本身不会出图。仍可直接发送 `/画图 横图 orange cat`，它会把这个快捷请求保存为你的当前草稿。旧的「画面」「角色1」等写法仍可使用。

## 草稿与重画

动态编辑按钮会把这条面板生成时该栏的完整提示词填入 QQ 输入框。例如「负向」会填入 `/画图 负面 tag1，tag2`，修改后发送即替换这一栏。要读取最新草稿，请重新发 `/草稿`。配置了固定编辑按钮模板时，需要将其 ID 留空才能使用动态预填。

每位成员在每个群分别保存草稿及历史。切回原群即可继续编辑。升级前的共享草稿与缺少来源群的早期记录保存在数据库中，不自动分配到任何群。已有来源群的图片记录可在原群继续使用，原图的「查看提示词 → 覆盖草稿」可恢复为本群个人草稿。数据保存在 AstrBot 持久化 data/plugin_data/astrbot_plugin_nai_groupdraw/drafts.sqlite3，不按时间清理，不存图片。每张成功图片的提示词与画幅单独保存；如果稍后编辑了草稿，旧图的按钮仍可重用该图参数。每次请求重新抽取种子并占用一次绘图额度。执行对应范围的清理指令后，已删除记录对应的旧图按钮失效。v1.2 只在内存里保存草稿，升级前可自行复制需要保留的旧稿。

## 管理员设置

在插件配置的「群白名单」中点「添加条目」，每群添加一条。填写在该群 @机器人 发送 `/标识` 得到的群标识。「群昵称」可填写便于辨认的备注。识别群和计数都使用群标识，改昵称不会影响额度。

「本群上限」留空时跟随「每群默认上限」，填 0 暂停该群出图，填正整数则只为这个群设限。清空本群上限即可恢复跟随默认值。删除整个条目并保存会撤销该群绘图权限。各群独立计算近 24 小时内的出图和重画次数，每个名额在满 24 小时后释放。

从 v1.8.1 更新并重载后，原白名单里的群会自动成为条目，原有单群上限和每群默认上限会保留。只在旧「指定群上限」里出现的群不会放行。新版沿用原有 `budget.sqlite3`，改昵称、调整额度或用同一群标识重新加入都不会重置有效期内的用量。

出图使用 V5 Full，普通尺寸 832×1216 或 1216×832，28 步，单张。使用独立成员 Token 时在配置里逐行填写 `用户标识=NOVELAI_TOKEN_ALICE`，并在运行环境设置同名变量。未启用成员映射时使用 NOVELAI_TOKEN 或插件的 API Token。可私聊机器人发送 `/标识` 获取本人的用户标识。

开启按钮时，插件使用 QQ 的 Markdown 图片素材接口，在同一条消息中先 @ 发起人，再显示图片和两个重画按钮。图片直接上传至 QQ。发送后释放本次临时素材，群里的图片副本可以继续查看。图片超过素材大小限制、卡片功能不可用或关闭按钮时，改发普通图片。QQ 明确拒绝内容时停止发送图片，尝试回复失败原因。发 `/再来一张` 或旧指令 `/再出一张` 会按原设置重画本人最近成功的一张。旧卡片的「再来一张」也按原设置重画。

新图片的两个重画按钮下方是「查看提示词」。同群允许绘图的成员都能查看这张图的完整画面和角色提示词。提示词消息提供本图预设开关和「覆盖草稿」。覆盖后机器人会展示点击者的草稿和编辑按钮。查看和覆盖均不消耗生图额度。每个按钮绑定其对应图片；旧图消息保留发送时的按钮。

图片与提示词消息使用动态按钮。旧版固定重画按钮模板不再使用。草稿编辑面板仍可使用配置好的编辑按钮模板。
