# QQ 群画图 v1.13.0

在 AstrBot 的插件页用本 ZIP 更新并重载同名插件。在手机 QQ 群实际 @机器人，发送 `/画图` 即可看到自己的草稿。所有交互在群内完成。绘图指令自行处理，未配置对话模型也可使用。

## 随出图指令附参考图

手机无法一起发送文字和图片时，可以先发一张图，在两分钟内长按这张图，选择「回复」，在回复框中 @机器人 并发送 `/测试引用`。这条指令检查 QQ 返回的原作者、原消息时间和图片附件，条件满足时实际下载并解码图片，全程不请求 NovelAI。测试成功后，再次回复原图发送 `/引用出图 参考模式：服装`。测试只需验证客户端时使用。

引用出图只处理能定位到的本人本群原图。缺少作者、原消息时间或可读取的附件时，机器人会说明情况并停止本次引用出图。进度消息会标明「引用图片」。使用普通 `/出图` 时，本条附图优先；QQ 明确提供消息引用时也支持原图。只提供上下文索引的客户端请使用 `/引用出图` 明确选择。插件只检查当前指令事件，不订阅群全量消息。

点草稿的「出图」会在输入框填入 `/出图 参考模式：角色`。可以把「角色」换成「画风」「服装」或「角色+画风」，在同一条 @机器人 消息中附图并发送。没附图时，参考模式整段都会被忽略；照常使用你在本群的草稿和当前预设。直接发 `/出图` 并附图时默认使用角色模式。同一条消息中的多张附件使用同一模式，强度为 1。图片下载或解析失败时，机器人会提示重新附图。

发送后，「正在画」会显示本次提交的参考模式和图片数量。若显示「本条消息未收到参考图」，此次按普通草稿出图。

V5 的服装参考使用 `costume`。v1.12.0 和 v1.12.1 记录的服装图，点击「按原设置重画」时也会自动采用修正后的参数。

普通出图每次只取当前消息的附件。「按原设置重画」会复用随原图记录保存的参考图。群内其他允许绘图的成员也可以通过原图卡片重画。「用我的预设重画」使用原图草稿和点击者的当前预设。

自定义键盘的「出图」按钮支持上述预填。使用 QQ 平台固定键盘模板时，请将已配置模板里的「出图」按钮数据同步改为 `/出图 参考模式：角色`，并关闭自动发送。

## 画风与质量预设

在群中 @机器人 发送 `/预设` 或点草稿上的「预设」。列表按页显示官方预设和本群共享预设，每项可以查看详情、启用或停用。首次使用时默认全部关闭。「我的拼接顺序」从左到右就是实际追加的顺序。选择仅对你在当前群生效，重启后保留。

| 编号 | 官方预设 | 作用栏 |
|---|---|---|
| N1 | 正向轻量 | 画面正向 |
| N2 | 正向标准 | 画面正向 |
| N3 | 反向轻量 | 画面负向 |
| N4 | 反向重度 | 画面负向 |
| N5 | 人物向 | 画面负向 |
| N6 | 兽人向 | 画面负向 |

在白名单群中，所有可用绘图的成员都可以新建和修改本群的自定义预设。点「新建预设」会预填模板，也可以一次发送这条多行消息：

```text
/预设 新建 水彩
正向：watercolor, textured paper
反向：hard outlines
```

至少填一侧。保存后查看机器人返回的 G 编号。点「详情 → 编辑预设」可以改昵称和两侧内容。手动编辑如 `/预设 修改 G1` 后另起一行填写 `昵称：晨光水彩` 或 `正向：…`。省略的栏保留原值，发送空栏如 `反向：` 会清空该侧。改名后已启用该项的人会继续使用同一预设。官方六项只读。

发送 `/预设 启用 N2 G1 N5` 按顺序追加这三项，G1 换成本群实际编号。发送 `/预设 停用 G1` 只移除这一项，`/预设 全关` 清空自己的选择。重复启用同一编号只计一次。普通出图与快捷出图都在提交时读取最新版本，只追加到基础画面正负向，角色栏独立。

「查看提示词」分栏展示原始草稿的画面和角色提示词，以及生成时各预设的名称、编号和正反向原文。可在同一张提示词卡片上按自己的状态开启或关闭这些预设；每行最多三个开关，每页最多四项，底行用于覆盖草稿和翻页。预设后来改过时，卡片注明开启将使用当前版本。两种重画都重新抽取种子。「按原设置重画」复用原图的生成参数和当时的预设。「用我的预设重画」读取原图的草稿提示词、角色和画幅，按点击者在本群当前的选择重新拼接预设。两种操作都保留点击者正在编辑的草稿。v1.11.0 开始保存实际提交的生成参数；更早的记录按旧版固定参数和已存的草稿、预设还原。新图单独记录本次实际使用的预设，旧图仍显示原有记录。「覆盖草稿」只替换点击者的画面和角色提示词，保留点击者的画幅与本群预设开关、顺序。

## 本群图库

从安装此版本起，每次收到 NovelAI 返回的 PNG，插件先把全部原图存入本群目录，再向 QQ 回复。原图保留 NovelAI 写入文件的元数据。存放位置是 AstrBot 持久化目录 `data/plugin_data/astrbot_plugin_nai_groupdraw/gallery/<群作用域哈希>/images/`，按机器人实例与群隔离。升级前只保留了提示词的记录无法补回原图。

| 在绘图白名单群 @机器人 | 效果 |
| --- | --- |
| `/图库权限` | 检查自己在本群的权限，显示 QQ 自动识别或手动授权的结果。 |
| `/导出图库` | 群主或本群管理员可把打包时本群的全部原图作为一个 ZIP 发到本群。原图继续保留。 |
| `/清空图库` | 群主或本群管理员可永久删除本群已归档的原图。个人草稿、重画记录、额度和其他群的图库均保留。已发送的 QQ 文件仍需在 QQ 中管理。 |
| `/清空提示词记录` | 群主或本群管理员可清除本群所有成员的历史提示词和重画记录。旧图的「查看提示词」「覆盖草稿」「再来一张」随之失效，原图和当前草稿保留。 |

这三条管理指令在 `/help` 中列出，直接发文字即可。按钮记录单独存在 SQLite 中，持续保留至本人清除或本群管理员清除。图库 ZIP 只包含原始 PNG。原始 PNG 自带的 NovelAI 元数据会随文件保留。机器人仅在出图群提供原图导出、提示词查看、覆盖和重画。

插件通过 QQ 群消息的发送者角色核验权限，消息缺少角色时才向 QQ 查询本群成员。若 QQ 无法返回角色，可请群主或管理员在对应群 @机器人 发送 `/群标识`，复制回复中的「你的用户标识」。在插件配置 → 群白名单 → 对应群 → 图库管理员中每行填写一人的用户标识并保存。手动授权仅在此群生效，包含导出图库、清空图库和清空提示词记录。QQ 明确返回普通成员时仍拒绝。如需撤销手动授权，删除该用户标识并保存。可在群中发 `/图库权限` 验证。导出走 QQ 群文件上传与被动回复接口，需要当前机器人具备相应权限。文件超过平台限制或 QQ 拒绝发送时会报告失败。

图库持续占用磁盘，直到管理员清空。打包期间需要约相当于本群原图总大小的额外空间，临时 ZIP 在发送完成或失败后释放。每个插件实例同时处理一个导出。新图和清空以本群图库的写入顺序为准，导出快照建立后归档的图片留待下次导出。剩余磁盘空间低于 144 MiB 时暂停新生图。

## 编辑个人草稿

点击角色行最右侧的「删除」，即可移除自己在本群草稿中该角色的正向和负向提示词。草稿随即刷新，其他角色保留原编号。也可直接发送 `/删除角色 2` 删除角色 2。

草稿预览只列已填写的字段，每栏最多显示 36 个字符（含省略号）。编辑按钮会带出原文，图片的「查看提示词」也会显示全文。

草稿标题优先显示发送者的昵称；消息缺少昵称时，QQ 按钮面板用群成员 @ 标签显示名字，纯文本回复显示「你的草稿」。

每个角色占一行，正向和负向按钮并排显示。超过三个角色时，用「下一页」和「上一页」切换角色按钮。点击「添加角色」仍会预填第一个空闲角色编号的正向指令。

| 目的 | 群内指令示例 |
|---|---|
| 查看草稿 | `/画图` 或 `/草稿` |
| 查看绘图说明 | 在群内 @机器人 发 `/help` 或 `/画图 帮助`，尚未加入白名单的群也可以使用 |
| 查看本群标识和你的用户标识 | `/群标识` |
| 切换画幅 | `/横图` 或 `/竖图` |
| 编辑画面 | `/画图 画面正向 train station`，`/画图 画面负向 watermark` |
| 编辑角色 | `/画图 角色1正向 girl, blue hair`，`/画图 角色2负向 hat` |
| 清空一栏 | 只发送字段名，例如 `/画图 画面正向` 或 `/画图 角色1负向`。发送后直接显示更新的草稿和按钮 |
| 用当前草稿生成 | `/出图` |
| 重画某张图 | 点「按原设置重画」或「用我的预设重画」，对应文字指令为 `/原设置重画 图片编号` 和 `/我的预设重画 图片编号` |
| 重画最近成功的一张 | `/再出一张` |
| 清空当前草稿 | 点「清空」或发送 `/清空草稿`，返回默认竖图的空草稿。历史图片仍可重画和查看提示词。旧指令 `/取消画图` 同样只清空当前草稿 |
| 清除本人的历史出图记录 | 在绘图群单独发送 `/清除记录`，会清除本人在当前群的全部历史出图记录，保留当前草稿。旧图的重画、查看与覆盖指令随记录失效 |

每个已有角色的正向、负向入口同时保留。角色编号 1～6。按钮可以预填指令，填完发送。只填画面负向、只填角色或不填任何提示词时，也可以点「出图」，空正向会作为空字符串提交。选方向、开草稿或按编辑按钮本身不会出图。仍可直接发送 `/画图 横图 orange cat`，它会把这个快捷请求保存为你的当前草稿。旧的「画面」「角色1」等写法仍可使用。

## 草稿与重画

动态编辑按钮会把这条面板生成时该栏的完整提示词填入 QQ 输入框。例如「负向」会填入 `/画图 负面 tag1，tag2`，修改后发送即替换这一栏。要读取最新草稿，请重新发 `/草稿`。配置了固定编辑按钮模板时，需要将其 ID 留空才能使用动态预填。

每位成员在每个群分别保存草稿及历史。切回原群即可继续编辑。升级前的共享草稿与缺少来源群的早期记录保存在数据库中，不自动分配到任何群。已有来源群的图片记录可在原群继续使用，原图的「查看提示词 → 覆盖草稿」可恢复为本群个人草稿。数据保存在 AstrBot 持久化 data/plugin_data/astrbot_plugin_nai_groupdraw/drafts.sqlite3，不按时间清理，不存图片。每张成功图片的提示词与画幅单独保存；如果稍后编辑了草稿，旧图的按钮仍可重用该图参数。每次请求重新抽取种子并占用一次绘图额度。执行 `/清除记录` 后，已删除记录对应的旧图按钮失效。v1.2 只在内存里保存草稿，升级前可自行复制需要保留的旧稿。

## 管理员设置

在插件配置的「群白名单」中点「添加条目」，每群添加一条。填写在该群 @机器人 发送 `/群标识` 得到的群标识。「群昵称」可填写便于辨认的备注。识别群和计数都使用群标识，改昵称不会影响额度。

「本群上限」留空时跟随「每群默认上限」，填 0 暂停该群出图，填正整数则只为这个群设限。清空本群上限即可恢复跟随默认值。删除整个条目并保存会撤销该群绘图权限。各群独立计算近 24 小时内的出图和重画次数，每个名额在满 24 小时后释放。

从 v1.8.1 更新并重载后，原白名单里的群会自动成为条目，原有单群上限和每群默认上限会保留。只在旧「指定群上限」里出现的群不会放行。新版沿用原有 `budget.sqlite3`，改昵称、调整额度或用同一群标识重新加入都不会重置有效期内的用量。

出图使用 V5 Full，普通尺寸 832×1216 或 1216×832，28 步，单张。使用独立成员 Token 时在配置里逐行填写 `用户标识=NOVELAI_TOKEN_ALICE`，并在运行环境设置同名变量。未启用成员映射时使用 NOVELAI_TOKEN 或插件的 API Token。可在群里用 `/群标识` 获取当前两个标识。

开启按钮时，插件使用 QQ 的 Markdown 图片素材接口，在同一条消息中先 @ 发起人，再显示图片和两个重画按钮。图片直接上传至 QQ。发送后释放本次临时素材，群里的图片副本可以继续查看。图片超过素材大小限制、卡片功能不可用或关闭按钮时，改发普通图片。QQ 明确拒绝内容时停止发送图片，尝试回复失败原因。发 `/再来一张` 或旧指令 `/再出一张` 会按原设置重画本人最近成功的一张。旧卡片的「再来一张」也按原设置重画。

新图片的两个重画按钮下方是「查看提示词」。同群允许绘图的成员都能查看这张图的完整画面和角色提示词。提示词消息提供本图预设开关和「覆盖草稿」。覆盖后机器人会展示点击者的草稿和编辑按钮。查看和覆盖均不消耗生图额度。每个按钮绑定其对应图片；旧图消息保留发送时的按钮。

图片与提示词消息使用动态按钮。旧版固定重画按钮模板不再使用。草稿编辑面板仍可使用配置好的编辑按钮模板。

QQ 指令联想在 QQ 开放平台「发布设置 → 功能配置 → 指令配置」选择群聊，配置 群标识、画图、横图、竖图、草稿、出图、清空草稿、再出一张。本版不提供 HTML 表单或 6198 端口服务，旧版本配置的在线画板链接将失效。
